# Опис модулів системи

## 📌 Загальна інформація

Модулі системи реалізують основну логіку обробки зображень та класифікації емоцій. Кожен модуль виконує окрему функцію в загальному pipeline.

---

## 🧩 1. image_processor.py

### 🔹 Призначення

Підготовка зображення до подальшої обробки та аналізу.

### 🔹 Основні функції

* Зменшення шуму, за допомогою Білатерального методу;
* Застосування Гаусівського фільтру;
* Нормалізація експозиції (CLAHE);
* Конвертація в grayscale.

### 🔹 Приклад

```python
processed = preprocess(face_image)
```

---
## 🧩 2. face_detector.py

### 🔹 Призначення

Модуль відповідає за виявлення обличчя на зображенні, використовуючи каскади Хаара.

### 🔹 Основні функції

* Детекція обличчя за допомогою алгоритмів комп’ютерного зору;
* Використання каскадів Хаара, котрі грунтуються на алгоритмі Віоли-Джонса;
* Виділення необхідної області.

### 🔹 Приклад використання

```python
faces = detect_faces(image)
```

### 🔹 Особливості

* Працює з бібліотекою OpenCV
* Може повертати декілька облич

---

## 🧩 3. emotion_classifier.py

### 🔹 Призначення

Основний модуль, використовується для класифікація емоцій за допомогою навченої моделі. На вхід отримується область зображення та аналізується. В результаті отримуємо значення ймовірностей для кожного класу емоцій.

### 🔹 Основні функції

* Завантаження моделі;
* Обробка виділенної області зображення;
* Визначення значення ймовірностей для кожного класу.

### 🔹 Приклад

```python
emotion = classifier.predict(image)
```

### 🔹 Особливості

* Використовує TensorFlow / Keras
* Працює з .h5 моделями

---

## 🧩 4. result_handler.py

### 🔹 Призначення

Модуль обробки результатів класифікації для подальшого відображення. Використовується для коректного представлення визначених значень ймовірностей.

### 🔹 Основні функції

* Визначення найбільш ймовірної емоції;
* Форматування результату в графічний інтерфейс;
* Скомпонування в детальний звіт.

### 🔹 Приклад

```python
result = format_result(predictions)
```
