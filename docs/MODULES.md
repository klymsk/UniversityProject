# Опис модулів системи

## 📌 Загальна інформація

Модулі системи реалізують основну логіку обробки зображень та класифікації емоцій. Кожен модуль виконує окрему функцію в загальному pipeline.

---

## 🧩 1. face_detector.py

### 🔹 Призначення

Модуль відповідає за виявлення обличчя на зображенні.

### 🔹 Основні функції

* Детекція обличчя за допомогою алгоритмів комп’ютерного зору
* Вирізання області обличчя

### 🔹 Приклад використання

```python
faces = detect_faces(image)
```

### 🔹 Особливості

* Працює з бібліотекою OpenCV
* Може повертати декілька облич

---

## 🧩 2. image_processor.py

### 🔹 Призначення

Підготовка зображення перед передачею в нейронну мережу.

### 🔹 Основні функції

* Зміна розміру (resize)
* Нормалізація пікселів
* Перетворення у потрібний формат

### 🔹 Приклад

```python
processed = preprocess(face_image)
```

---

## 🧩 3. emotion_classifier.py

### 🔹 Призначення

Класифікація емоцій за допомогою навченої моделі.

### 🔹 Основні функції

* Завантаження моделі
* Передбачення емоції
* Обчислення ймовірностей

### 🔹 Приклад

```python
emotion = classifier.predict(image)
```

### 🔹 Особливості

* Використовує TensorFlow / Keras
* Працює з .h5 моделями

---

## 🧩 4. result_handler.py

### 🔹 Призначення

Обробка результатів класифікації для подальшого відображення.

### 🔹 Основні функції

* Визначення найбільш ймовірної емоції
* Форматування результату

### 🔹 Приклад

```python
result = format_result(predictions)
```

---

## 🔄 Взаємодія модулів

```text
FaceDetector → ImageProcessor → EmotionClassifier → ResultHandler
```

---

## 📌 Висновок

Модульна структура дозволяє легко масштабувати систему та змінювати окремі компоненти без впливу на інші частини.
