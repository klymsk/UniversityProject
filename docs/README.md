# Система розпізнавання емоцій людини

## 📌 Опис проєкту

Даний програмний комплекс призначений для автоматичного розпізнавання емоційного стану людини за зображенням обличчя. Система використовує методи комп’ютерного зору та глибокого навчання для визначення емоційного стану.

Основна ідея полягає у:

1. Виявленні обличчя на зображенні
2. Попередній обробці даних
3. Класифікації емоції за допомогою нейронної мережі
4. Відображенні результату користувачу

---

## 🎯 Основні можливості

* Завантаження зображення
* Детекція обличчя
* Класифікація емоцій (happy, sad, angry тощо)
* Графічний інтерфейс користувача
* Швидка обробка зображень
