# Програмний комплекс ідентифікації емоцій людини за зображенням

## 📌 Опис проекту

Даний проект призначений для автоматичного розпізнавання емоційного стану людини за зображенням обличчя. Система використовує методи комп’ютерного зору та глибокого машинного навчання для визначення емоційного стану.

Основний алгоритм виконання є наступним:
1. Попередня обробка вхідного зображення;
2. Виявлення обличчя на зображенні;
3. Класифікація виявлених емоцій за допомогою нейронної мережі;
4. Відображення результату користувачу.

---

## 🎯 Основні можливості
* Завантаження зображення;
* Обробка зображення;
* Детекція обличчя;
* Класифікація емоцій (happy, neutral, surprise тощо);
* Графічне зображення результатів.

## 🧠 Як працює система

Pipeline обробки:

```
Зображення → Обробка → Детекція обличчя → Нейромережа → Результат
```

Для початку користувач завантажує вхідне зображення. 

Після чого є можливість запустити попередню обробку, яка включає застосування фільтрів для зменшення шумів та нормалізації експозиції.

Після, виконується етап детенкції обличчя на фото,
а також ідентифікації виявленого емоційного стану.

Результат формалізується, та виводиться користувачу.

## 🤖 Нейронна модель

Для функціонування методу розпізнавання емоційного стану, використовується згорткова нейронна мережа (CNN), яка використовує підхід з transfer learning із застосуванням попередньо навченої архітектури MobileNetV2. 

Детальні відомості, щодо нейронної моделі знаходяться у файлі **MODEL.md**
