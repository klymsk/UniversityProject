# Архітектура системи

## 🏗️ Загальний опис

Система побудована за модульним принципом, що дозволяє розділити логіку на незалежні компоненти. Кожен модуль відповідає за окремий етап обробки даних. 

---

## 🔁 Загальний pipeline
1. Користувач завантажує зображення;
2. Існує можливість застосування попередньої обробки зображення;
3. Система ідентифікує обличчя;
4. Нейронна мережа визначає емоційний стан;
5. Результат відображається в GUI користувачу.

---

## 🧩 Основні компоненти

### 1. Image Processor

Перший модуль виконує попередню **обробку зображення**. Даний етап включає в себе, застосування Білатерального фільтру, Гаусівського фільтру та нормалізацію експозицію (CLAHE)

Виконує:

* Зміну розмірності;
* Нормалізацію;
* Підготовку до подальшої обробки.

---

### 2. Face Detector

Другий модуль відповідає за **детекцію обличчя на зображенні**. Використовує каскади Хаара для знаходження необхідної облсті по ключовим ознакам. В свою чергу, ознаки обличчя виявляються за принципом Віоли-Джонса. 

Метод використовує два каскади для надання більш точних та якісних результатів в розпізнаванні. 

Виконується:

* Пошук обличчя на зображенні;
* Виділення області обличчя;

---

### 3. Emotion Classifier

Третій модуль є основним, адже в ньому виконується **розпізнавання емоційного стану**. Відповідно, за допомогою налаштованої та навченої нейронної моделі, виконується аналіз виділеної області та надається значення ймовірностей для представлених класів емоцій.

Виконує:
* Завантажує модель;
* Аналіз вхідної області;
* Визначає значення ймовірностей класів.

---

### 4. Result Handler

Четвертий модуль, відповідає за виведення результатів користувачу. На вхід отримується значення ймовірностей класів та обробляється для коректного виведення результатів в графічному інтерфейсі.

Виконує:
* Обробляє результат;
* Форматує дані для GUI.

---

### 5. GUI

Окремий модуль графічного інтерфейсу, який надає комфортну взаємодію з функціоналом програмного комлпексу. Користувач може завантажити вхідне зображення, обрати які методи обробки потрібно застосувати та почати процес аналізу. Після обробки, в області попереднього перегляду, користувач зможе побачити виділену область ідентифікованого обличчя та значення виявленої емоції. 

Також є можливість побачити детальний звіт, де буде представлено значення виявлених емоцій у відсотках, в форматі зростання. 


Виконує:
* Взаємодія з користувачем;
* Графічне відображення результатів.
