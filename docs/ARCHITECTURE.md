# Архітектура системи

## 🏗️ Загальний опис

Система побудована за модульним принципом, що дозволяє розділити логіку на незалежні компоненти. Кожен модуль відповідає за окремий етап обробки даних.

---

## 🔁 Загальний pipeline

1. Користувач завантажує зображення
2. Система знаходить обличчя
3. Зображення нормалізується
4. Нейронна мережа визначає емоцію
5. Результат відображається у GUI

---

## 🧩 Основні компоненти

### 1. Face Detector

Відповідає за:

* пошук обличчя на зображенні
* виділення області обличчя

---

### 2. Image Processor

Виконує:

* зміну розміру
* нормалізацію
* підготовку до подачі в модель

---

### 3. Emotion Classifier

* завантажує модель
* виконує попередній аналіз
* повертає ймовірності класів

---

### 4. Result Handler

* обробляє результат
* форматує дані для GUI

---

### 5. GUI

* взаємодія з користувачем
* відображення результатів

---

## 📐 Принципи проєктування

* Модульність
* Розділення відповідальності (SRP)
* Масштабованість
* Повторне використання коду

---

## 🔄 Взаємодія модулів

```
GUI → FaceDetector → ImageProcessor → EmotionClassifier → ResultHandler → GUI
```
